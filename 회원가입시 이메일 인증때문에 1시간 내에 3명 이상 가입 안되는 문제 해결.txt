[회원가입시 이메일 인증때문에 1시간 내에 3명 이상 가입 안되는 문제 해결 방법]
1. 확인/설정 방법: Supabase 대시보드 접속 -> 좌측 메뉴 Authentication -> Providers -> Email 항목을 열어 "Confirm email" 설정이 꺼져(Off) 있는지 확인합니다.
2. Rate Limits (가입 속도 제한) 수치 늘리기
이메일 서버 문제와 별개로, Supabase 자체적으로 같은 IP나 전체 서비스에 대해 시간당 가입자 수를 제한하는 설정이 있습니다.

확인/설정 방법: Supabase 대시보드 접속 -> 우측 상단 톱니바퀴 Project Settings -> Authentication -> 스크롤을 내려서 Rate Limits 섹션을 확인합니다.
이곳에 있는 "Max signups per hour (시간당 최대 가입자 수)" 등의 수치가 3이나 낮게 설정되어 있다면 100이나 1000 등으로 넉넉하게 변경해 줍니다.
3. 외부 커스텀 SMTP(이메일 서버) 연결 (정식 서비스용)
만약 이메일 인증 기능이 반드시 필요해서 유지해야 했다면, Supabase의 기본 메일러 대신 SendGrid, Resend, Amazon SES, 구글 메일 등 외부 메일 서버(Custom SMTP)를 연결하여 해결하셨을 것입니다.

확인/설정 방법: Supabase 대시보드 접속 -> 우측 상단 Project Settings -> Authentication -> 스크롤을 내려 SMTP Settings 가 활성화되어 있고 정보가 입력되어 있는지 확인합니다.
결론적으로: 동시 가입자에 대한 제한이 다시 걸리는 것을 막기 위해서는 Supabase 대시보드에 접속하셔서 위 세 가지(특히 1번과 2번) 설정이 어떻게 되어있는지 점검하시는 것이 좋습니다.

현재 "S&J Dream Archive" 웹사이트의 대시보드에 접속하신 뒤, 위 설정들 중 확인이나 변경이 필요하시면 말씀해 주세요!

1. 이메일 인증 활성화 끄기 (가장 유력한 방법) 방법으로 해결했어. 그런데, 이후에 새로운 이메일과 이름을 입력후 회원가입완료 버튼을 클릭하니 이메일 인증을 해달라는 팝업메시지가 나와. 이 메시지와 함께 '이메일 인증 시스템이활성화 되어 있는 경우' 와 같은 안내 문구도 있긴 했지만, 새로 가입하는 사람들은 이메일 인증을 해야 하는 줄 오해할 수도 있을것 같아. 현재로서는 보안이 아주 엄격하지 않으므로 일단 메일 인증 활성화를 끈 상태로 운영하고 싶어. 그렇다면, 새롭게 회원가입하는 사람들에게는 가입정보를 모두 입력후 '회원가입완료' 버튼을 눌렀을때 기존 팝업 메시지 대신에 다음 문구를 보여주었으면 좋겠어.  '회원가입이 완료되었습니다. 가입시 입력하신 정보로 로그인 하시기 바랍니다'
