3. API 키 교체 및 무중단 배포 적용
신규 키 발급: Supabase에서 현대적인 방식의 안전한 신규 공개 API 키(sb_publishable_hu_...)를 발급했습니다.
배포 서버 적용: 운영 중인 Vercel 서버의 환경 변수를 새 키로 갱신하고 재배포하여, 청소년들이 이용 중인 아카이브 서비스 중단 시간(Downtime) 0초로 무중단 적용을 마쳤습니다.
구형 키 차단: 이전에 GitHub 퍼블릭 저장소에 노출되었던 구형 Legacy API 키들을 Supabase에서 최종 비활성화(Disable)함으로써, 잠재적이었던 해킹 및 데이터 유출 취약점을 완벽히 차단했습니다.
